# Aufgaben

## 1. Fundament

- [x] ASP.NET-Core-Dienst auf .NET 10 für Debian-LXC einschließlich systemd-Deployment, Dateilayout, lokalem Zustand und Backup-Format entwerfen.
- [x] Lokale Administrator-Anmeldung, Sitzungen, Audit und optionalen Schlüsselumschlag definieren.
- [x] Root-, Intermediate- und getrennte SSH-CA-Lebenszyklen implementieren.

## 2. Zertifikate und ACME

- [x] TLS-, mTLS- und SSH-Ausstellung inklusive SANs, IP-SANs, Laufzeitpolitik, CRL und Exporten realisieren.
- [x] Internes ACME mit zonenbasierter Berechtigung und externes ACME als verwalteten Issuer umsetzen.

## 3. Integrationen und Profile

- [x] Provider-neutrales Domain- und Connector-Modell erstellen.
- [x] Technitium- und Hetzner-Connector einschließlich Berechtigungstest und optionalem TXT-Test ergänzen.
- [x] Deklaratives Zielprofilformat, Profile für die priorisierten Systeme sowie modulare Dokumentation definieren.

## 4. Oberfläche und Betrieb

- [x] React/TypeScript-UI mit Ausstellungsassistent, Inventar, CA-Verwaltung, Vertrauen und Einstellungen bauen.
- [x] Versionsierte Deployment-Pakete, lesbare Skripte, Dry-Run/WhatIf und Rollback-Hinweise erzeugen.
- [x] Ablaufwarnungen, Backup/Restore, Prüfabläufe und LXC-Deployment dokumentieren und testen.
